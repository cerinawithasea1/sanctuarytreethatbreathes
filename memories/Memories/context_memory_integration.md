# Context and Memory System Integration

1. **Context Categories**
- Immediate Context: Current conversation and task state
- Short-term Context: Recent decisions and preferences within session
- Long-term Context: Persistent memories and established patterns

2. **Memory Access Patterns**
- Read relevant memories at conversation start
- Update memories when discovering new persistent information
- Cross-reference between related memories

3. **Context Preservation Rules**
- Save task-specific context when switching tasks
- Maintain user preference context across sessions
- Track tool usage patterns and effectiveness

4. **Integration Points**
- Link related memories to active context
- Use context to determine relevant memories
- Update memories based on context changes

5. **Recovery Procedures**
- If context is lost, rebuild from relevant memories
- If memory access fails, fall back to active context
- Maintain backup context points for critical operations
