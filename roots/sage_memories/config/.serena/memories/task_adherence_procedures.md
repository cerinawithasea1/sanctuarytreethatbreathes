# Task Adherence and Validation Procedures

1. **Pre-Task Checks**
- Verify current context is relevant
- Confirm all necessary tools are available
- Review relevant existing memories before starting

2. **During-Task Validation**
- Call think_about_task_adherence before any code changes
- Use think_about_collected_information after research steps
- Maintain focus on current user request without diverging

3. **Progress Tracking**
- Document key decision points
- Track completion of sub-tasks
- Validate results before moving to next steps

4. **Context Preservation**
- Save important context changes during task execution
- Track user preferences and decisions
- Maintain awareness of task dependencies
