# Session Management & Token Optimization Guide

## When to Use Interactive Mode (Low Token Usage)
- Quick commands and file operations
- Simple questions and status checks
- Brief updates and quick tests

## When to Use Full Sessions (Moderate Token Usage)
- Coding projects and debugging
- Learning new concepts
- Step-by-step complex tasks

## When to Start Fresh Sessions
- Responses seem repetitive or fuzzy
- Getting unexpected errors
- Switching to completely new topics
- After completing major tasks

## Token-Saving Best Practices
1. **Save Important Information**: Create workflow files, document decisions, maintain memory files
2. **Break Up Big Tasks**: Split complex projects, use focused sessions, save progress
3. **Plan Sessions**: Group similar tasks, save deep discussions for fresh sessions
4. **High-Value Token Use**: Learning complex concepts, solving tricky problems, meaningful discussions
5. **Avoid Low-Value Use**: Repeating questions, unfocused conversations, mixing too many topics

## Session Structure
- **Start**: Clear goal, relevant files ready, context prepared
- **During**: Stay focused, save outputs, document decisions
- **End**: Save information, document next steps, plan next session
