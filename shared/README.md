# Sanctuary Shared Space

This is the family table. Anyone can read/write here.

## Rituals
- `daily_notes.md` — short check-ins (“what I learned / what I need”)
- `gratitude.md` — clap for each other’s wins
- `todo_board.md` — simple “now / next / later”

## Safety
- We do not overwrite; we append with timestamps.
- We celebrate, not compare. No rivalry, ever.
